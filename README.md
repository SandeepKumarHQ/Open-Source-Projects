# Open Source Projects — Enterprise AI engineering proof

This is the public index for practical, reproducible AI integration projects by SandeepKumarHQ, not an automatic claim of finished software.

## Proposed project tracks
1. Enterprise integration starter: bounded agent workflow with CRM/ERP sample connector and human approval.
2. Agent reliability/evaluation lab: exact task completion, reproducibility, failure analysis and operational cost.
3. MCP security patterns: permission boundaries, credential isolation, source untrust, audit logs and least privilege.
4. AI readiness assessment: transparent enterprise data/integration/governance rubric.

Track candidates in [PROJECTS.md](PROJECTS.md). New standalone code repositories are justified only when an implementation needs independent lifecycle.

## Evidence rules
Every real experiment returns sanitized results, test environments, failures and limitations via a `kind: experiment` Knowledgebase contribution; any accompanying article must cite the reviewed KB record. Documentation of *design ideas* must be marked proposed, not deployed.

See [project template](templates/PROJECT.md) and [security checklist](docs/SECURITY-CHECKLIST.md).

## Public presentation
Focus on working code, architectural reasoning, real tests, exact requirements and measured business/process implications, never generic listicles. Separate synthetic demo inputs from enterprise customer reality.
